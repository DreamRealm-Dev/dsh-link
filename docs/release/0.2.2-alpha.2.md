# 0.2.2-alpha.2 实验版（v0.1.0-experimental.1）

本版把内核基线从 `dsh-v0.2.1-rc.2` 升到 **`dsh-v0.2.2-alpha.2`**（tag commit `f3803c96`，2,176 个
commit），并把 LINK 的补丁系列 rebase 到该 tag 上（分支 `dsh-link/multilevel-team`，HEAD
`1ee84404fa`，11 个文件 +1189/−49）。

## 内核侧

- 唯一冲突：upstream 把 Agent Teams 的 `[Service.init]` 改成异步并注册 projection handle；合并时
  保留多层 Team 的 `maxDepth / teammatesMaySpawn / interruptScope` 策略。
- 两处内核接口变更使测试夹具需要重绑：`SessionEventsPage`（历史页现在带 inclusive `cursor`）、
  工具执行器（`ToolBatchInput` 批量模型调用替代单次 callId/name/arguments）。行为不变，单独一个
  commit 记录（R512）。
- 补丁文件按新 base 重新生成：R484 45,318 B / 6 文件，R459 2,526 B / 1 文件，R501 33,388 B / 4 文件。
  `R510-draft.patch` 仍是未应用草稿，需要按新 base 重做。
- 上游同版本新增 `subagent-codex` / `subagent-claude-code` 等 out-of-process 委派 provider bundle，
  与本项目既有的“统一 Agent 协作总线”方向一致。
