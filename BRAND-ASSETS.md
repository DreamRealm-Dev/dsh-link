# Brand assets — licence and usage scope

## English

### Two licences, two scopes

DSH Link is deliberately split into two works with two licences:

| Work | Licence | Where |
|---|---|---|
| Source code — the Tauri shell, every plugin's code, scripts, docs | **MIT** ([LICENSE](LICENSE)) | this repository |
| Brand artwork — the DSH Link mark, wordmark, mono/white variants, application-icon plates | **CC BY-NC-SA 4.0** ([canonical repository](https://github.com/DreamRealm-Dev/dsh-link-brand)) | that repository, mirrored here under `plugins/dsh-link-brand/assets/`, `src-tauri/icons/` (renders of the mark) and the boot-page mark |

The artwork is separated so the boundary is mechanical: the MIT licence above covers code, and it does
**not** cover the brand artwork. The canonical copy, its full legal text and the complete usage scope
live in <https://github.com/DreamRealm-Dev/dsh-link-brand> (`LICENSE`, `USAGE.md`).

### What the artwork licence allows

- Share and adapt the artwork for **non-commercial** purposes, with attribution and under the same
  licence (CC BY-NC-SA 4.0).
- Use the unmodified marks to refer to the project (articles, reviews, listings, "works with DSH Link"
  statements) without implying endorsement.

### What it does not allow

- Commercial use of the artwork, or use of the name/mark as another product's or organisation's identity.
- Registering the DSH Link name or a confusingly similar mark.
- Implying endorsement or affiliation with DSH Link, its contributors, or DeepSeek / DeepSeek Harness.
  DSH Link is a third-party desktop edition and has no official affiliation.
- Derivative branding that keeps the artwork recognisable under a different name or product.

### Attribution

> "DSH Link brand artwork" by DSH Link contributors, licensed under CC BY-NC-SA 4.0.
> Source: https://github.com/DreamRealm-Dev/dsh-link-brand. Modified versions must be marked as modified.

### Trademark

No trademark licence is granted. DeepSeek and DeepSeek Harness are trademarks of their respective
owner; this project neither uses their marks nor claims affiliation. The DSH Link name and mark are
used by this project to identify itself, and the NC-SA licence above is what keeps them from being
absorbed into a commercial product.

## 简体中文

### 两条许可，两个范围

DSH Link 刻意拆成两件作品、两条许可：

| 作品 | 许可 | 位置 |
|---|---|---|
| 源码——Tauri 外壳、各插件代码、脚本、文档 | **MIT**（[LICENSE](LICENSE)） | 本仓库 |
| 品牌素材——DSH Link 标志、字标、单色/白色变体、应用图标底板 | **CC BY-NC-SA 4.0**（[规范仓库](https://github.com/DreamRealm-Dev/dsh-link-brand)） | 该仓库；本仓库内在 `plugins/dsh-link-brand/assets/`、`src-tauri/icons/`（标志的位图产物）与启动页标志中是镜像副本 |

素材独立成库，边界就是机械的：上面的 MIT 只覆盖代码，**不覆盖**品牌素材。素材的规范副本、完整
法律文本与完整使用范围见 <https://github.com/DreamRealm-Dev/dsh-link-brand>（`LICENSE`、`USAGE.md`）。

### 素材许可允许

- 以**非商业**目的共享、改编，需署名并以同一许可（CC BY-NC-SA 4.0）发布。
- 原样使用标志来指向本项目（文章、评测、收录、“可与 DSH Link 配合使用”等），但不得暗示获得背书。

### 素材许可不允许

- 商业使用素材，或把名称/标志当作其他产品或组织的身份。
- 把 DSH Link 名称或易混淆的近似标志注册为商标。
- 暗示与 DSH Link、其贡献者、或 DeepSeek / DeepSeek Harness 存在背书或关联。DSH Link 是第三方
  桌面版，与官方无隶属关系。
- 在保留可识别性的前提下换成别的名称或产品的衍生品牌。

### 署名

> 来源：https://github.com/DreamRealm-Dev/dsh-link-brand。修改过的版本必须标注为已修改。

不授予任何商标许可。DeepSeek 与 DeepSeek Harness 是其各自权利人的商标；本项目既不使用其商标素材，
